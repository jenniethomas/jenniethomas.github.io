# Author-name conventions

How author names are displayed on the publications page, which names were
verified against which sources, and what to do when a new paper introduces a
name that cannot be resolved automatically.

The publications page is generated by `tools/build_pubs.py`. **That script is
the authoritative, machine-readable source** for all name data — the tables
below mirror its Python structures one-to-one. When you change one, change the
other. For step-by-step publication workflows see `UPDATING.md`; for the build
history see `HISTORY.md`.

## Display rules

Every author renders as **first name in full, middle names as initials**
("Jennie L. Thomas", "William R. Simpson").

| # | Rule | Example |
| --- | --- | --- |
| N1 | First names full, middle names reduced to initials | Marianne Tronstad Lund → "Marianne T. Lund" |
| N2 | Hyphenated compound first names are one name; never abbreviated | "Jean-Christophe Raut", "Sang-Woo Kim" |
| N3 | Compound surnames (Spanish/Portuguese order) keep the full given string — the second token is a surname, not a middle name | "Carlos Pérez García-Pando", "Beatriz Ferreira Araujo" |
| N4 | Names whose published form carries a leading initial keep it; expand only when the person actually publishes a fuller form (their own website/publications page is authoritative) | "V. Faye McNeill", "W. Richard Leaitch", "V. Holly L. Winton", "R. Benny Gerber" |
| N5 | Diacritics are preserved as the person uses them | "Gaël Le Roux", "Bjørn H. Samset", "Petr Klán" |
| N6 | Typography is normalised: non-breaking hyphens (U+2010) become ASCII "-", non-breaking spaces become spaces | |
| N7 | Jennie is bolded: any author with family "Thomas" and a given name starting with "J" (displayed as "Jennie L. Thomas") | |
| N8 | A candidate full name is only accepted if its first letter(s) match the Crossref initials — other people's names are never substituted | "J. Kim" never becomes "Jochen Kim" |
| N9 | Names that cannot be expanded stay as initials; the build script lists them so the list cannot silently regress | see below |

## How a name is built (pipeline order)

1. **Crossref** supplies the raw author list (given, family), cached per
   publication in `tools/crossref_cache.json` under `cr_authors`.
2. **Aliases**: `GIVEN_ALIASES` normalises spelling variants.
3. **First-name expansion** (only when the given name starts with an initial):
   `MANUAL_NAME_FIXES` first, then OpenAlex author profiles (cached in
   `tools/openalex_cache.json`). Rule N8 guards every expansion.
4. **Middle abbreviation**: `abbrev_middle` applies rules N1/N2/N4, skipped
   for families in `MIDDLE_KEEP_FAMILIES` (rule N3).
5. Bold Jennie (N7), escape for HTML, join with commas.

## Adding a new paper: checklist

1. Add the tuple to `PUBS` in `tools/build_pubs.py` and run
   `python3 tools/build_pubs.py` (`UPDATING.md` has the full procedure).
2. Read the build output:
   - `No DOI found for: <title>` → add the DOI to `DOI_OVERRIDES`.
   - `<n> author name(s) still show only initials` → verify each name
     (ORCID is best; OpenAlex author profiles and publisher pages are good
     backups), then add it to `MANUAL_NAME_FIXES` — or to
     `INTENTIONALLY_ABBREVIATED` if no source can verify it. Update the
     tables above at the same time.
3. Skim the rendered entry on the publications page: full first names,
   middle initials, Jennie bolded, venue and pages correct.
4. Beware rule N8 when verifying: a plausible-looking first name must match
   the initials. Where memory and sources disagree, the checked source wins
   (that is how "Anke Roiger" and "Gabriele Pfister" were caught).
